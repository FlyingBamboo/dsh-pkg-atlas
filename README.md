# dsh-pkg-atlas

本机 DSH 包依赖图谱：一个独立 HTTP 页面，展示当前 DSH_HOME 已安装的官方
`@deepseek-ai/*` 包与第三方插件之间的依赖与挂载关系。图谱按功能大类分区、
组为复合节点、包在组内成网格，首屏有扫描进度。零运行时依赖、纯本机数据、
只读、全离线可用。

页面地址（安装并重启后）：`http://127.0.0.1:3080/dsh-pkg-atlas/`

## 图谱三层结构

大类区（功能分类：内核·装配 / 会话·状态 / 界面 / LLM·模型 / 编排 / 平台 / 工具 /
集成 / 基础设施，外加插件、profiles、断链、未归类四个特殊区）→ 组
（`repository.directory` 推导的功能组，复合容器节点）→ 包（组内网格）。
节点坐标由视图模型按展开态维度预分配（无布局引擎）：展开/折叠/筛选不重排、
不移动，只重建元素集合，因此位置在交互间保持稳定。

## 它回答什么问题

- 某个工具/插件在 DSH 生态里的位置：属于哪个大类、哪个功能组、被谁依赖、挂了哪些 bundle。
- 一个官方 bundle（如 `dsh-base`）到底把哪些包挂载进 profile（BFS 展开
  `cordis.patch.yml` 的 `name:` 行）。
- 哪些目录断了链（broken junction，标红伪节点）、哪些版本区间装不到满足版本
  （红色 unsatisfied 边）。

## 安装（web profile）

    dsh plugin --profile web add link:D:/codes/harness-dev/dsh-pkg-atlas
    # 重启 DSH 后打开
    http://127.0.0.1:3080/dsh-pkg-atlas/

## 卸载

    dsh plugin --profile web remove dsh-pkg-atlas
    # 重启后人工核对 profiles/web/package.json 的 dsh.profile.bundles 中
    # 无 "dsh-pkg-atlas" 残留行（本插件自身无运行时状态，无其它残留面）

## 页面用法

- 三层图谱与显示粒度：顶栏两态开关 组级 | 包级 就是视图模型 `view.granularity`
  本身（默认 组级）。v2.3 起**没有「自动」档，缩放不再改变结构**：自动 LOD 在浏览器里
  会被包标签拖垮——标签旧钳宽 96px 大于网格行内中心距 CELL 46 + GAP 12 = 58，
  同排相邻包的居中标签横向互相压字（组框/区框钉在 data(w)/data(h) 且标签不计入
  复合包围盒，不会随标签变宽——压到的是文字；短名看不出来，scoped 长名必现），
  而翻阈值还要整体重建常驻的上百个包标签。修正方式是钳标签而不是猜层级：包标签
  钳到 50px（伸不进隔壁列），层级完全交给这两颗按钮（切换按结构性变更处理、
  整体重建；v2.5 起重绘一律保留视口，镜头不再跟着结构走——见「复位视图」）。
  滚轮缩放灵敏度 2.5（v2.2b 起，滚一格约等于旧版两格半）。「组级」下单击组卡片 =
  选中（详情面板），双击 = 展开/收拢该组；进入**组聚焦**走右键菜单或深链；
  双击大类区标题 = 折叠整区（v2.2b
  曾被 inert 化的组卡双击语义在此恢复；组聚焦内仅当前根组卡保留该手势）；「包级」下该层由模型
  全展开，双击组卡是有意空操作；双击大区在包路径内仍为空操作。**包级档由应用装配层
  强制打开真实跨包线**（v2.4a 撤组级常驻边后，包级无边可看是 UX 倒退；复选框的
  用户原值保留，切回组级即恢复）。搜索/路径命中/
  面板成员行点击仍会自动展开祖先。
- 组聚焦（v2.4b）：右键组卡 →「聚焦邻域（1 跳）」（或深链 `#node=g:<组名>`）进入该组
  **1 跳邻域**——邻居组卡（组已展开或包级档时
  为成员包）按方向着色：琥珀 = 该组依赖的下游、青 = 依赖它的上游（含挂载攀爬）、
  洋红 = 双向；组级渲染同时出现**聚合边**（粗细∝触碰边计数；R43 撤组级常驻边后，
  聚合边现在**只在组聚焦内出现**），根卡保留金色选中环但不染方向，祖先转虚线上下文。
  深度下拉期间禁用（恒 1 跳）。点邻居组卡 = 走栈换根；点成员包 = 转入依赖图；
  双击根组卡 = 保持聚焦展开它；点空白 / Esc 退出（v2.7 起零镜头，不再滑回）。详情面板出现
  **相关组（N）/ 相关包（N）**段：行 = 方向箭头 + 名称 ×计数 + 边型徽章 +（断链区 ⚠），
  按 down→up→both、名称排序；组行点击 = 焦点走该组，包行点击 = 以该包进依赖图。
  深链 `#node=g:<组名>` 可直接分享一个组聚焦。
- 右键命令菜单（v2.5）：右键任意目标弹出**它自己的命令行**——组卡：展开⇄合并 /
  聚焦邻域（1 跳，组已展开时为包形态）/ 只看该区；大类区：折叠该区⇄展开该区 /
  只看该区 / 隐藏该区；包：依赖图（v2.7 R48 前的「路径模式」）；空白画布：复位视图 / 退出聚焦。不可用的行
  **置灰而不是消失**（包级档的合并、别人聚焦下的展开/折叠、非法路径根的「依赖图」、
  无聚焦时的「退出聚焦」），灰行的判定与双击门是同一套谓词。菜单出现在点击处
  （贴边自动翻转到框内），只关闭不选中：关闭它的那一下点击被吞掉，下一次点击
  照常工作；平移 / 缩放 / 窗口缩放 / 任何结构重绘都会收起它；Esc 优先级：
  菜单 > 搜索结果 > 退出聚焦。右键边（edge）不弹菜单——没有对应命令。
- 复位视图（v2.5，顶栏 ⌂ 或空白画布右键）：把**当前渲染集**整体 fit 回视野
  （padding 40、250ms 补间），只动镜头，不改聚焦/选中/折叠/快照。它是旧「结构变更
  自动 refit」的显式替代：v2.5 起重绘一律保留视口（重扫也不再挪镜头）；v2.7 R50 后
  相机只在三处移动——首屏 fit 一次、搜索/深链定位的居中闪烁、⌂/菜单的复位——全部经
  `cy.animate`（首屏那次除外）。「进/走依赖图滑到路径」「退聚焦滑回进入前视图」
  连同进入前视口快照链（`state.viewport`/snapshot/restore 一族）已整体退役。
- 首屏进度：扫描按 目录清单→manifest 读取→组装 三阶段推进，进度条实时显示
  已扫/总数（`/api/status` 轮询）；服务端启动即预热，通常首屏即缓存就绪。
- 大类筛选 chips：单击 = 隐藏该区（再点恢复）；双击 = 单独显示该区（其余全隐藏，
  同颗再双击恢复全部）；行尾「全部显示 / 全部隐藏」按钮批量开关。官方/第三方、
  边类型（mount/peer/dep/peer-optional）、profile 挂载面、真实跨包边开关、
  深浅主题、中英切换、显示粒度两态开关均在顶栏。
- 悬停速览卡：在任何节点（含路径内节点）停留 250ms 弹小卡——名称@版本、
  大类 · 组、截断描述、直接依赖/直接被依赖计数（按路径语义计数，mount 不计
  下游）、⚠ 含未满足边 / 断链包标记；纯只读，不改变聚焦与选中，移开/平移/
  缩放/点击即收起。
- 搜索：包名或中文描述，回车项点击定位（自动展开祖先）。
- 聚焦：界面名 v2.7 R48 起为**依赖图**（旧称「路径模式」），进入后双向高亮其依赖路径与被依赖路径——琥珀色为它
  依赖的下游，青色为依赖它的上游，洋红为双向/成环成员；琥珀/青两色同时出现在
  图例（左下角），非路径元素淡出，祖先容器不再"陪绑"而是虚线半透明的上下文框。
  **v2.7 R50 零镜头：进入/换根/退出依赖图一律不挪视口**——旧版「滑到路径」
  「滑回进入前视图」连同视口快照链一起退役，想找回全局视野按 ⌂。**v2.6 收口：冷态下单击（左键）任何节点 = 纯选中**
  +详情（包与组对称，v2.1 的左键自动聚焦正式退役）；进入依赖图的全部入口是
  **显式导航**：右键包 →「依赖图」；**双击任意包**（与菜单同一函数同一门，v2.7 R49；依赖图内双击亮包 = 换根行走，
  组卡双击的展开/收拢语义不受影响）；详情面板的路径行/挂载行/跳转按钮；表格行；
  搜索命中定位；深链 `#node=<id>`。聚焦激活期间的点击语义不变：再点另一个包 = 沿路径行走，前一个根
  进入顶栏面包屑「← 返回 (a → b → c)」，返回按钮逐级回退（最多记 20 步，显示
  最近 4 级）；点空白、Esc 或「退出依赖图」按钮退出。
  深度默认「不限」（顶栏可选 1-3）；路径内取消勾选的边类型直接隐藏（区别于
  淡出的非成员）；仅包节点可作路径根（点空白/类型/profile 即退出；点组卡则焦点
   走为该组的组聚焦，见上文组聚焦）；
  URL hash 可分享深链（`#node=<id>`，打开即按不限深度展开定位）。挂载 `mount`
  不是向下方向（X→mount→Y 意为 Y 沿挂载向上到 X），故某包挂载的内容单列在
  详情的「挂载 ↓」里。
- Esc 顺序（v2.5 起三级）：先关右键菜单，再关搜索结果面板，然后（不在输入框里时）
  退出聚焦；否则无操作。
- 详情（包节点）：大类/组/类型三级面包屑、描述、依赖路径 ↓ 与被依赖路径 ↑ 两条完整列表，
  按 BFS 层分档折叠——d1（直接命中）默认展开，d2 起收在「d2 (N)」档头后面，
  点档头开合；每层最多列 60 行（超出显示 +N 更多，旧版是全局 60 行）；
  每行 `名称@版本 · d{层数} · 边型徽章 · ⚠`，点击即以该行为根进入/换根路径
  （profile 行不是合法路径根，点击即退出依赖图）。另有挂载 ↓、外部依赖、README 原文。
- 组卡 / 大类区详情 = **成员包列表**（v2.3；大类区自 v2.7 R51 起**按组分节**，见下）：表头「成员包（N）」的 N 永远是真实
  总数（与列表是否被截断无关），每行 `名称@版本 [类型] [第三方] ⚠断链包 ⚠未满足`
  ——`未满足` 沿用路径列表的口径（任何一条触碰边 unsatisfied 即标 ⚠），断链包是
  `kind=broken` 的伪节点。行按 名称→版本→id 全序排列，最多渲染 200 行，超出显示
  「+N 更多」。点任意成员行 = 走搜索定位同一条 `revealNode` 通路：展开它的区与组、
  以它为根进入依赖图、居中闪烁，并顺带收起速览卡；点断链包这类非法路径根则
  选中并退出路径（R35 口径不变）。
- 大类区详情按组分节（v2.7 R51）：区内成员按所属组分节列出，组名**字母序**；节头是
  「组名 ×组内总数」的可点按钮——点击 = 纯选中该组（`selectNode('g:'+gid)`，零导航，
  组聚焦语义不变），节内成员行仍是缩进的 revealNode 通路；每组最多列 10 行，超出显示
  「还有 N」。
- 详情面板层级分带（v2.7 R51）：区/组/包三级详情容器各带 `lvl-zone/lvl-group/lvl-pkg`
  类与 h2 标题徽章「区/组/包」（i18n），区详情按固定色板画 `data-zone` 左缘色带、
  三级标题字号递减——一眼看出当前面板停在哪一层；边详情保持无级中性面板。
- 图例（左下角，v2.7 R52 起靠左）：4 种节点形状 + 5 种边类型 + 聚焦两色（依赖路径 ↓ / 被依赖路径 ↑），
  可折叠。
- 「重扫」按钮强制重扫（快照缓存 60s TTL）；扫描中进度条重新走条。

## 已知边界

- 每次视图状态变更（展开/折叠/筛选/聚焦/切粒度）都整体重建 cytoscape 元素集合，
  无元素级增量动画；换来的是零布局引擎、坐标确定可测（vendored cytoscape 3.x 已无
  compound collapse/expand API）。相机移动（进/走/退路径、聚焦定位、复位视图）是唯一例外：
  全部经 `cy.animate` 视口补间（外加首屏一次性 fit），不触碰元素结构（v2.5 起
  自动 refit 退役，重绘后镜头永远停在用户留下的位置）。
- 包节点标签钳 50px 并省略号收尾（v2.3）：包网格的行内中心距只有 CELL 46 + GAP 12
  = 58，再宽就必然伸手进隔壁列。完整名称看速览卡与详情面板，图上不追求可读全名。
  这一条只能人眼在浏览器里验收：headless cytoscape 没有字体度量，测不出标签宽度。

## 安全模型

- 无任何写操作；路由只读（GET/HEAD），非 GET 一律 405。
- `/api/readme` 的 `id` 仅用于在扫描快照中查节点，文件路径取自扫描结果内部字段，
  用户输入永不参与路径拼接；恶意 id 在正则卫生层即 400。
- 响应不回显内部错误文本（500 → `{error:'internal-error'}`）；所有响应
  `X-Content-Type-Options: nosniff`；页面 CSP 限定 `default-src 'self'`。
- 图数据中的路径一律相对化为 `$DSH_HOME/...`，不泄露绝对路径。
- 若启用 DSH 远程访问（tailscale/配对等），本页面与 `/api/graph` 的包清单一并
  暴露给可达者，请视为知情选择。
