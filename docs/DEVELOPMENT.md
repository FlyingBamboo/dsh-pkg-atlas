## 布局坐标教义

节点坐标由视图模型按展开态维度预分配（无布局引擎）：大类区按声明序流式紧排
进横向带（v2.9a R58：各区按自身实际宽高从左到右排，排满 `BAND_W` 换带，带高＝带内
最高区，不再等宽分列留空洞）；区内组卡同理按 `FLOW_W` 换行。展开/折叠/筛选不
重排、不移动，只重建元素集合，位置在交互间保持稳定。

常量在 `web/graph-model.js` 的 `ZONE_LAYOUT`：

| 常量 | 值 | 含义 |
|---|---|---|
| `CELL` | 46 | 包槽位边长（展开网格） |
| `GAP` | 12 | 包槽位 / 组卡 / 区行间距 |
| `ZONE_GAP` | 32 | 区内带之间、带内区之间的间距 |
| `BAND_W` | 2000 | R58：单条区带的最大宽度，换带阈值 |
| `FLOW_W` | 480 | 区内组卡行的最大行宽 |

判据两处：区内组卡换行看 `row.w + L.GAP + gr.slotW > L.FLOW_W`；区内带换带看
`bandX > 0 && bandX + zz.w > L.BAND_W`，换带时 `bandY += bandH + L.ZONE_GAP`，带高取带内
最高区。真实 home 实排 13 区 3 带。

## LOD 与标签钳宽的沿革

v2.3 起没有「自动」档，缩放不再改变结构。自动 LOD 在浏览器里会被包标签拖垮：标签旧钳宽
96px 大于网格行内中心距 CELL 46 + GAP 12 = 58，同排相邻包的居中标签横向互相压字（组框/区框
钉在 data(w)/data(h) 且标签不计入复合包围盒，框不会随标签变宽，压到的是文字；短名看不出来，
scoped 长名必现），而翻阈值还要整体重建常驻的上百个包标签。修正方式是钳标签而不是猜层级：
包标签钳到 50px（伸不进隔壁列），层级完全交给顶栏两颗按钮，切换按结构性变更处理、整体重建。

这条推导线在代码里也有：`web/app.js` 包样式那行的注释指出 CELL(46)+GAP(12)=58 来自
`graph-model` 的 `ZONE_LAYOUT`，`'text-max-width': 50` 就落在它下面。注意拼写必须是
`text-max-width`——vendored 的 flattened dist 会静默丢掉 `max-text-width` 这种拼错的属性。

这一条只能人眼在浏览器里验收：headless cytoscape 没有字体度量，测不出标签宽度。完整名称
走速览卡与详情面板，图上不追求可读全名。

滚轮缩放灵敏度 2.5（v2.2b 起，滚一格约等于旧版两格半）。

## 交互语义沿革（为什么现在长这样）

- v2.2b：组卡双击语义曾被 inert 化，v2.3 恢复；组聚焦内仅当前根组卡保留该手势。
- v2.3：撤掉「自动」粒度档；标签钳宽从 96px 收到 50px（见上一节）。
- v2.4a：撤组级常驻边。之后包级无边可看是 UX 倒退，所以包级档由应用装配层强制打开
  真实跨包线，复选框的用户原值保留，切回组级即恢复。
- v2.4b：组聚焦（1 跳邻域）与 `#node=g:<组名>` 深链。
- v2.5：右键命令菜单、复位视图按钮；重绘一律保留视口，旧的「结构变更自动 refit」退役。
  Esc 收口为三级（菜单 > 搜索结果 > 退出聚焦）。
- v2.6：冷态左键自动聚焦（v2.1 引入）正式退役，包与组对称。
- v2.7：R48「路径模式」改名依赖图；R49 双击包与菜单行是同一函数同一门；R50 零镜头——
  相机只在四处移动（首屏 fit、搜索/深链居中闪烁、复位视图、自动排布），「进/走依赖图滑到
  路径」「退聚焦滑回进入前视图」连同进入前视口快照链（`state.viewport`/snapshot/restore
  一族）整体退役；R51 区详情按组分节 + 面板层级分带；R52 图例靠左。
- v2.8：详情面板信息分层与去重（scope 前缀上提为徽章、同版本上提组头、颜色=信息类型，
  全部取自画布既有调色板并由守卫钉死，正文对比度 ≥WCAG-AA）。
- v2.9a：R58 区带流式紧排（见布局教义）；R59 拖动主权——手动拖动落在渲染层覆盖表
  `state.dragged`，重绘时优先于模型槽位，模型永不可见拖动。
- v2.10b：R64 全量解耦，拖拽语义全归渲染层：拖父框实时平移整棵子树，落点把父与每个
  被带动的子级各记绝对位；compound 的「祖先跟随」副作用明确取消（手动摆好的父框不该被
  一次包的挪动改写）。
- v2.10c：四个截断面板尾行（区组节 / 组成员页 / 路径层 / 挂载出）从灰色死字改成
  真注册的「展开更多」按钮。

## 维护者向的已知边界

- 每次视图状态变更（展开/折叠/筛选/聚焦/切粒度）都整体重建 cytoscape 元素集合，无元素级
  增量动画；换来的是零布局引擎、坐标确定可测（vendored cytoscape 3.x 已无 compound
  collapse/expand API）。相机移动是唯一例外：全部经 `cy.animate` 视口补间（外加首屏一次性
  fit），不触碰元素结构。
- 大类映射表是维护品（`lib/categories.js` 的 `GROUP_TO_CATEGORY`，现 47 个目录组键）：新增
  `packages/*` 目录组未入表时默认落「未归类」，人工补表；未知组永远落表外而不丢节点。
  2026-09-26 用真实 home 实扫核对：47 键全部在用（此前记录的「46 在用 + 1 前瞻」已过期）。
- `repository.directory` 不以 `packages/` 开头的官方包（如 `apps/cli`、`apps/web`、
  `native/system/*`）落「未归类」区：组派生只认 `packages/<组>` 模式。当前真实 home 有 3 个：
  `@deepseek-ai/dsh`、`@deepseek-ai/dsh-web-frontend`、`@deepseek-ai/node-addon-system`。
- 官方包 package.json 的 cordis 服务清单字段覆盖率约 1/240（cordis vendor 系），
  「消费服务」仅在有值时显示。2026-09-26 实扫复核：真实 home 240 个官方包节点，
  仅 1 个 `servicesRequired` 非空。
- 真实 home 的断链目录当前 4 个（`dsh-client-runtime`、`dsh-host-apiproxy`、
  `dsh-tool-subagent-report`、`node-addon-landlock-run`），可与浏览器清单里的对表命令核对。
